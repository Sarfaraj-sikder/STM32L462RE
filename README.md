STM32L462RE – Bare-Metal Programming

This repository contains small, hands-on projects using the STM32L462RE, an ultra-low-power Arm Cortex-M4 microcontroller from the STM32L4 family.

The main goal is to revise and strengthen my bare-metal embedded C programming skills by working directly with microcontroller peripherals and registers, while exploring the fundamentals of low-power embedded systems. The plan is to slowly explore all the peripherals that the Discovery board B-L462E-CELL1 provides.
